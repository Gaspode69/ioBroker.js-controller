# Windows Admin controller update test

**Only use this package on a disposable Windows test installation. Data loss cannot be ruled out.**

This package is technically js-controller 7.2.5, so adapters requiring `js-controller >= 7.2.5` continue to run. For this test only, the host object advertises 7.2.4 to Admin. Admin can therefore offer the official 7.2.5 update, which replaces the complete test controller again.

The German installation and test instructions will be added after both the controller and Admin artifacts have been uploaded and their immutable download URLs have been verified.
